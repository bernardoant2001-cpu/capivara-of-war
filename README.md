# Capivara of War

Age of War, só que com capivaras.

**Jogar:** https://bernardoant2001-cpu.github.io/capivara-of-war/

## Rodar local

```
npx serve
```

Testes da lógica: `node test.js`

## Controles

- `1` `2` `3` treinam unidades
- `←` `→` / `A` `D` / arrastar movem a câmera
- `P` / `Esc` pausa
- `F3` mostra o fps
